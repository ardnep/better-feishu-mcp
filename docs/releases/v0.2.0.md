# better-feishu-mcp Release (MCP 0.2.0)

## ✨ What's new

- **More of Feishu from your existing login:** 88 new tools cover Sheets writes and formulas, Drive transfers and import/export, Base data, Wiki management, document comments, calendars, task-related operations, reactions and pins. With writes enabled, the normal catalog now contains 106 tools.
- **Editable content and practical transfers:** Create and update spreadsheet tabs, work with Base tables/fields/records, import local content into documents, and export documents to new local files. Uploads and downloads are bounded to 5 MB and never overwrite an existing destination.
- **Direct writes without repeated local approvals:** Normal document and productivity tools reuse the authorized user login. Writes remain opt-in; legacy prepare/commit tools stay hidden by default. Persistent credential renewal and explicitly reviewed extra scopes remain supported.

## 🐞 Bugs fixed

- **Calendar pagination:** Lists now respect Feishu's minimum page size of 50; event listing uses an anchor rather than mixing pagination with a silently truncated time-window query.
- **Spreadsheet formulas and empty boards:** Formula writes use native formula objects instead of storing literal formula text. Boards with omitted/null node arrays read back correctly after their last nodes are deleted.
- **Comment diagnostics:** Feishu content-review rejection is reported explicitly instead of suggesting another login or permission grant.

## 📒 Internal

- **Safer product expansion:** Fixed endpoints, strict bounded inputs, user-scope checks, identity/query-bound cursors, per-target write locks and no automatic mutation retries. No new permissions, tenant-token fallback, sharing administration, message sending, document search or task creation/completion were added.
- **Verified, with limits stated:** 204 automated tests and five auth-harness checks passed, along with credential-free and live stdio validation. Disposable live tests covered Sheets, Base, Drive import/export/transfers, private calendars/events, availability, comments and board deletion; cleanup requests succeeded. The broader live runner correctly exits nonzero because Feishu rejects reply creation with content-review error `1069302`.
- **Still alpha:** Board-node updates remain unavailable without a verified public API. Wiki writes, task ancillary writes, chat mutations, reply update/delete and document-media downloads are fixture-tested but not live-validated. See the [coverage and validation limits](https://github.com/ardnep/better-feishu-mcp/blob/v0.2.0/docs/productivity-coverage.md). Reconnect your MCP client after rebuilding to load the new tools; the existing authorized login remains reusable.
