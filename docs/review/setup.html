Use an absolute Node 24 path if your client cannot find Node. Enable writes by changing the startup flag to “1”—approval is still required per change.

How does a document edit work?
  1. The assistant reads the document and its block IDs.
  2. It prepares an exact change with a ten-minute expiry.
  3. You review and approve it in a trusted local terminal.
  4. The assistant commits that operation once.

A model cannot approve a change through this MCP. An unrestricted agent with OS shell/keychain access is outside that boundary; a terminal is not proof of human presence.

Login and diagnostics
node dist/cli.js status
node dist/cli.js doctor --probe-keychain
node dist/cli.js login --app-id cli_YOUR_APP_ID --auth-mode confidential
node dist/cli.js logout

Enter secrets in the local browser form, never in the command. Login defaults to PKCE; confidential mode is an explicit non-PKCE option that worked in the tested account. No refresh scope was added. Offline access remains an opt-in, unverified feature.

What exactly was verified?

30 automated tests and 14 live MCP checks passed. Coverage includes scope checks, HTTP limits, login, refresh races, approval integrity/replay/expiry, modern stdio and a legacy 2025-11-25 exchange; a real macOS keychain write/read/delete probe; and fixture-only Feishu calls through the built server.

The live checks rejected an unapproved write, verified an edit, deleted only the newly created test document and confirmed that it was no longer readable. Token-free evidence is in .runtime/mcp-stdio-live.json. The dependency audit is clean at this build checkpoint.

Limits of this first build
  • Modern Docx only. Simple text CRUD is live-tested; tables/media and lossless Markdown editing are not implemented.
  • DMs, threads, normal multi-person groups, shared-document permissions and non-macOS platforms need broader live coverage.
  • Revision preflight is best-effort, not a guaranteed atomic multi-user edit.
  • No automatic rollback or retry after uncertain writes.
  • No public release or license decision yet. This is a local alpha, not an independently audited product.
